# Contributing

Small fixes and reports from other trainers are welcome. Keep the app focused on bridging; workouts and training dashboards belong on the cycling computer.

Start with [Development & releases](docs/development.md). Run the formatter, linter, and tests before opening a pull request. For radio changes, say which devices you tried and what remains unverified. The D100 + Edge 530 is the priority setup.

For a bug report, include the app/Windows versions, trainer and cycling-computer models, ANT USB ID/driver, and steps to reproduce. **Copy error** and **Open logs** help. Remove Bluetooth addresses and other personal information before posting logs.

Please leave generated executables, logs, local settings, and downloaded reference code out of commits. Release ZIPs belong on the releases page.
